# JDBC Comiccon — демонстрация JDBC + PostgreSQL

Консольное приложение на **Java 21** + **JDBC** + **PostgreSQL**, демонстрирующее работу с реляционной БД на примере системы комик-кона.

## Требования

- [Java 21 JDK](https://adoptium.net/)
- [Maven 3.9+](https://maven.apache.org/)
- [PostgreSQL 17](https://www.postgresql.org/download/) (локально или Docker)
